---
title: "Clean Code"
description: "Nommage, fonctions courtes, gestion des exceptions, code review — les habitudes qui rendent un code lisible par quelqu'un d'autre que son auteur."
cascade:
  type: concept
---

Le code est lu bien plus souvent qu'il n'est écrit. Ces fiches couvrent les habitudes concrètes — pas des règles de style arbitraires — qui déterminent si un code reste compréhensible six mois plus tard, par quelqu'un qui n'est pas vous.
