Un code qui fonctionne n'est pas forcément un code sûr ou rapide. Cette section couvre les vulnérabilités web les plus courantes (le classement OWASP), la manière de s'en protéger, et les bonnes pratiques de performance côté PHP — deux sujets qui reviennent très souvent en entretien backend.
